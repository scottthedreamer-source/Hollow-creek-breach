# Hollow Creek Breach

A first-person clear-house tactical shooter that runs in the browser. Breach a two-storey farmhouse and garage and neutralise every armed bot before the five-minute clock runs out.

Play: https://scottthedreamer-source.github.io/hollow-creek-breach/

Works with keyboard and mouse or an Xbox controller (including Microsoft Edge on Xbox; allow Edge to use the controller for the game when it asks).

Built with three.js r128 (MIT licence, bundled as `three.min.js`).
